## ✅ OPÇÃO 2: CRIAR CONTA GITHUB E EU FAÇO O REST

### Passo a Passo para você:

1. **Acesse:** https://github.com
2. **Clique em:** "Sign up" (canto superior direito)
3. **Preencha:**
   - Email: seu email
   - Password: escolha uma senha
   - Username: escolha um nome de usuário
4. **Verifique** seu email
5. **Clique em:** "+" (canto superior direito) → "New repository"
6. **Preencha:**
   - Repository name: `sistema-igreja`
   - Description: `Sistema de gestão para igreja`
   - Public
   - **NÃO** marque "Initialize with README"
7. **Clique em:** "Create repository"
8. **Copie a URL** que aparece (exemplo: https://github.com/seu-usuario/sistema-igreja.git)

### Depois me diga a URL e eu faço:

```powershell
git remote add origin SUA_URL_AQUI
git branch -M main
git push -u origin main
```

Depois vou no Render e faço deploy automático!
