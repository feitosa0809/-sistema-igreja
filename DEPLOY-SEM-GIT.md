# 🚀 DEPLOY SUPER FÁCIL - SEM GIT!

## ✅ MÉTODO 1: GLITCH (MAIS FÁCIL - 2 MINUTOS)

### **Não precisa de Git, GitHub, nada!**

### Passo a Passo:

1. **Acesse:** https://glitch.com
2. **Clique em:** "Sign up" (cadastro grátis com email)
3. **Clique em:** "New Project" → "glitch-hello-node"
4. **Agora copie os arquivos:**

#### 📁 Estrutura que vamos criar no Glitch:

```
projeto/
├── server.js (backend)
├── package.json
├── public/ (frontend)
│   ├── index.html
│   ├── pagamentos.html
│   ├── aniversariantes.html
│   └── assets/
```

### 5. **No Glitch, edite `package.json`:**
Copie o conteúdo do seu `package.json` atual.

### 6. **Crie `server.js` na raiz:**
Copie o código do `backend/server.js` e cole lá.

### 7. **Crie pasta `public`:**
- Arraste todos os arquivos do `frontend` para dentro de `public/`

### 8. **PRONTO!** 
URL automática: `https://seu-projeto.glitch.me`

## ✅ MÉTODO 2: VERCEL (SEM GIT - UPLOAD DIRETO)

### Passo a Passo:

1. **Acesse:** https://vercel.com
2. **Cadastre-se** grátis com email
3. **No dashboard, clique:** "Add New" → "Project"
4. **Selecione:** "Upload" (fazer upload direto)
5. **Arraste** a pasta `tcc1` inteira
6. **Configure:**
   - Build Command: `npm install`
   - Output Directory: `public`
7. **Deploy!**

URL: `https://sistema-igreja.vercel.app`
