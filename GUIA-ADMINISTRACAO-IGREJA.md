# 👥 ÁREA DE ADMINISTRAÇÃO DA IGREJA

## 🏛️ **ONDE FICA A ÁREA DOS DADOS DA IGREJA**

### **📍 Localização da Administração:**

A área de dados e administração da igreja está localizada em:

**🌐 URLs de Acesso:**
- **Computador:** http://localhost:3001/admin.html
- **Celular/Tablet:** http://192.168.4.12:3001/admin.html
- **Outros Devices:** http://192.168.4.12:3001/admin.html

---

## 🔑 **COMO ACESSAR A ADMINISTRAÇÃO**

### **Método 1: Pelo Sistema Principal**
1. Faça login no sistema: http://192.168.4.12:3001
2. No menu superior, clique em **"Administração"**
3. Será redirecionado automaticamente para o painel admin

### **Método 2: Acesso Direto**
1. Digite diretamente: http://192.168.4.12:3001/admin.html
2. Faça login com uma conta de administrador
3. Acesse todas as funcionalidades admin

## 📊 **FUNCIONALIDADES DA ÁREA ADMINISTRATIVA**

### **1. 📈 Dashboard**
- Total de usuários cadastrados
- Total arrecadado (geral e mensal)
- Transações pendentes
- Gráficos de arrecadação
- Estatísticas em tempo real

### **2. 🏛️ Dados da Igreja**
- **Informações Básicas:**
  - Nome da Igreja
  - CNPJ
  - Endereço completo
  - Telefone e Email
  - Pastor responsável

- **Configurações:**
  - Moeda (Real/Dólar)
  - Fuso horário
  - Notificações
  - Backup automático

### **3. 👥 Gestão de Usuários**
- Lista todos os usuários cadastrados
- Alterar tipo de usuário (membro → tesoureiro → pastor → admin)
- Ativar/desativar contas
- Ver histórico de atividades
- Adicionar novos usuários

### **4. 💰 Gestão Financeira**
- **Transações Pendentes:**
  - Aprovar dízimos
  - Aprovar ofertas
  - Rejeitar transações

- **Resumo Mensal:**
  - Total de dízimos
  - Total de ofertas
  - Exportar dados financeiros

### **5. 📋 Relatórios**
- **Relatório Mensal** (PDF)
- **Relatório Anual** (PDF)
- **Relatório de Membros** (PDF)
- **Filtros Personalizados:**
  - Por período
  - Por tipo (dízimo/oferta)
  - Por status

- **Estatísticas:**
  - Maior doação
  - Média mensal
  - Contribuintes ativos
  - Taxa de crescimento

### **6. 📢 Campanhas e Projetos**
- Criar novas campanhas
- Definir metas financeiras
- Acompanhar progresso
- Gerenciar projetos especiais

### **7. 🗄️ Backup e Segurança**
- **Download de Backup:**
  - Backup completo dos dados
  - Formato JSON
  - Data automática no nome

- **Restaurar Backup:**
  - Upload de arquivo de backup
  - Validação de integridade
  - Confirmação de segurança

- **Histórico de Backups:**
  - Lista de backups realizados
  - Status dos backups
  - Logs de atividades

## 🚀 **COMO USAR CADA SEÇÃO**

### **Dashboard (Painel Principal):**
- Visualização imediata do status da igreja
- Gráficos interativos
- Cards informativos
- Acesso rápido às principais funções

### **Dados da Igreja:**
1. Preencha todas as informações da igreja
2. Clique em "Salvar Alterações"
3. Configure as preferências do sistema
4. Ative/desative notificações

### **Usuários:**
1. Veja lista completa de membros
2. Use botões de ação para editar/excluir
3. Altere permissões conforme necessário
4. Adicione novos usuários com botão "+"

### **Financeiro:**
1. Revise transações pendentes
2. Aprove ou rejeite conforme política da igreja
3. Monitore resumo mensal
4. Exporte dados quando necessário

### **Relatórios:**
1. Escolha tipo de relatório desejado
2. Configure filtros se necessário
3. Clique em "Gerar PDF"
4. Download automático do arquivo

### **Backup:**
1. **Para fazer backup:**
   - Clique em "Download Backup"
   - Arquivo será baixado automaticamente
   
2. **Para restaurar:**
   - Selecione arquivo de backup
   - Clique em "Restaurar Backup"
   - Confirme a operação
