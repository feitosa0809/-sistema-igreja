Validação de Cartão CORRIGIDA!

Agora é IMPOSSÍVEL cadastrar pagamento sem preencher os dados do cartão

Correções Implementadas:

Nome no Cartão

Obrigatório, mínimo 3 caracteres

Número do Cartão

Obrigatório, 13-19 dígitos, com formatação automática (espaços a cada 4 dígitos)

Validade (MM/AA)

Obrigatório, formato MM/AA, verifica se cartão não está vencido, valida mês (01-12)

CVV

Obrigatório, 3-4 dígitos, apenas números

Tipo do Cartão

Obrigatório, deve escolher entre Crédito ou Débito

Feedback Visual:

Campo Vermelho
Quando está inválido
Animação Shake
Chama atenção no erro
Mensagem Clara
Explica o que está errado

Como Testar:

  1. Acesse: http://localhost:3000/pagamentos.html
  2. Faça login com suas credenciais
  3. Preencha valor e tipo (Dízimo/Oferta)
  4. Selecione método: Cartão
  5. Tente enviar SEM preencher os dados do cartão
  6. Você verá: campo vermelho + shake + mensagem de erro
  7. Preencha os campos e veja o erro desaparecer!
Mensagens de Erro que Você Verá:
Informe o nome completo no cartão!
Número do cartão inválido! (13-19 dígitos)
Data de validade inválida! Use o formato MM/AA
Cartão vencido! Verifique a validade
CVV inválido! Digite 3 ou 4 números
Selecione o tipo do cartão (Crédito ou Débito)!
TESTAR AGORA A VALIDAÇÃO
Dica: Os erros somem automaticamente quando você começa a digitar no campo! Experimente!
